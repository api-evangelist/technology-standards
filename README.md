# Technology Standards

Technology Standards covers the landscape of formal technical standards, protocols,
and normative specifications developed by international standards bodies including
IEEE, IETF, W3C, ISO, OASIS, and the Linux Foundation. These standards define how
technology systems interoperate, communicate, and behave. In the API economy, key
standards govern data formats (JSON, XML, CSV), communication protocols (HTTP/2,
HTTP/3, WebSocket, gRPC), security (OAuth 2.0, OpenID Connect, TLS), identity
(SAML, SCIM), and API description (OpenAPI, AsyncAPI).

## Standards Bodies

### IETF Internet Standards

Produces Internet Standards (RFCs) covering HTTP, TLS, OAuth 2.0, JWT, JSON, and more.  
**Website:** https://www.ietf.org/  
**Datatracker API:** https://datatracker.ietf.org/api/v1/

Key RFCs:
- RFC 9110: HTTP Semantics
- RFC 6749: OAuth 2.0 Authorization Framework
- RFC 7519: JSON Web Tokens (JWT)
- RFC 8259: JSON Data Interchange Format
- RFC 9930: TEAP (Tunnel Extensible Authentication Protocol)

### W3C Web Standards

Develops Recommendations for web technologies including CORS, WebAuthn, JSON-LD, RDF.  
**Website:** https://www.w3.org/standards/  
**GitHub:** https://github.com/w3c

### IEEE Standards

Develops electronics, electrical engineering, and computer science standards including IEEE 802 networking.  
**Website:** https://standards.ieee.org/

### OASIS Open Standards

Develops SAML, OData, MQTT, AMQP, WS-Security, and OpenDocument standards.  
**Website:** https://www.oasis-open.org/  
**GitHub:** https://github.com/oasis-tcs

### OAuth and OpenID Connect

OAuth 2.0 (RFC 6749) authorization framework and OpenID Connect identity layer.  
**Website:** https://oauth.net/2/  
**Specification:** https://www.rfc-editor.org/rfc/rfc6749
